# Claude 大肥鱼角色包

包含 **Claude-大肥鱼-站立**、**Claude-大肥鱼-托腮** 两种形态，111 + 11 段透明动画，以及 13 + 5 条随机日常动作链。

![两种形态](../../docs/media/hero.png)

形象与动作预览见[项目首页](../../README.md)，安装和卸载方法见[安装说明](../../docs/INSTALL.md)。需要本分支的引擎才能使用原生换装、动作链与办公入场/收尾。

`manifest.json` 是发行清单，包含两份配置与 122 段 VP9-Alpha WebM；安装器校验文件哈希并保留已有实例偏好。动作链说明见 [ACTIVITY-CHAINS.md](ACTIVITY-CHAINS.md)。

敬礼、回眸素材留在 `sources/reference-actions/`，跳起后张臂的素材留在 `sources/happy-open-arms/`，包含提示词和逐帧编排。先前新设计的舞蹈均已撤下。安装包只按发行清单收录配置和视频，不包含制作工作区。
