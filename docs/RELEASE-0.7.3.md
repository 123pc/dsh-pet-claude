# dsh-pet-claude 0.7.3 · 接单敬礼与三个新动作

- 新增「抱文件认真敬礼」「转身回眸·发梢随风」「跳起后张臂」，共 122 段透明动画，右键动作菜单可以点播。
- 收到工作先敬礼一次，并显示“收到任务，马上开始！”，随后继续工作；步骤更新不重复敬礼，气泡恢复最新任务详情。
- 保留站立与托腮两种形态、随机日常动作链和托腮电脑办公衔接；新增回眸与开心张臂的日常活动。
- 从 0.7.2 升级时自动补充新素材；识别到旧版官方动作模板会先备份，再仅更新动作定义，保留尺寸、位置、显示模式和开关。自定义动作定义与修改过的视频不自动替换。
- 市场展示名统一为 **dsh-pet-claude**。内部包标识及数据目录仍为 `dsh-pet`，作为原版替代安装，请勿同时安装两者。

DSH 用户下载 `dsh-pet-claude.tgz`；Windows 独立版下载 `claude-dafeiyu-windows-x64.zip`，解压后双击 `启动桌宠.cmd`。角色 ZIP 供手动管理使用。插件包版本为 `0.3.8-claude.3`。

已在 Windows、DSH 0.2.1-rc.3 与 Electron 43.3.0 验收接单提示、三个动作播放及旧配置升级。源码测试 1735 通过、1 项跳过，UI 测试 31 通过、1 项跳过；完整发布前检查通过。macOS / Linux 尚未完成本批动作实机验收。

第三方许可证与固定版本源码随包提供，见 `THIRD-PARTY.md`、`THIRD-PARTY-SOURCE.zip`；完整性校验见 `SHA256SUMS.txt`。
