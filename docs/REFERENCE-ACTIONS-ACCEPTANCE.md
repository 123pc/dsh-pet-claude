# 三个新增动作的整合验收

本次整合抱文件认真敬礼、转身回眸·发梢随风、跳起后张臂。项目清单共 122 段透明视频、2 份形态配置；此前 119 段视频和已确认的敬礼、回眸视频均保持原文件。

## 接单和真实桌面播放

使用 Windows x64、DSH 0.2.1-rc.3 和 Electron 43.3.0，在独立 DSH_HOME、插件 profile 与 Electron userData 中安装最终开发 TGZ。安装后的宿主 bundle SHA256 与 TGZ 内一致。验收副本只增加 profile 隔离和只读的视频、气泡观察器，业务代码保持原字节。

- 新任务先播放一次敬礼并显示“收到任务，马上开始！”，随后接回工作动作；任务步骤更新不重复敬礼，气泡恢复最新任务详情。
- 失败状态切换到错误动作，工作取消恢复待机。
- 三个动作均观察到真实视频的 playing 和 ended：敬礼 2.75 秒、回眸 4.5 秒、跳起后张臂 3.209 秒；播放回执正常结束。
- 跳起后张臂选用 32 张完整人物画面，确认先离地再张臂、下降后落地缓冲；解码后的最高脚底离地约 45 像素。全片保留真实 alpha。

## 旧版升级

升级保护测试覆盖官方定义只更新一次、自定义动作和视频不变、升级规则损坏时不写入、已有备份被修改时不替换，以及既有的路径越界、链接保护和缺失文件初始化。
