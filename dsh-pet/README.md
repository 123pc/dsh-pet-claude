# dsh-pet-claude

Claude 打扮的大肥鱼桌宠，包含站立、托腮两种形态和 122 段透明动画。完整动作预览见[项目首页](https://github.com/123pc/dsh-pet-claude)。

安装本分支的预构建 TGZ 后重启 DSH，即会自动准备角色素材，不需要再下载角色 ZIP 或运行 PowerShell 安装器。新目录默认显示站立形态，右键 → **换装** 可切换托腮；新安装默认关闭自动碎碎念和余额查询，可在设置中自行开启。

0.7.3 新增抱文件认真敬礼、转身回眸·发梢随风和跳起后张臂；收到工作先敬礼并显示“收到任务，马上开始！”，再进入工作动作。

升级会补充缺失素材。若动作定义仍是 0.7.2 官方模板，先备份原文件，再仅更新动作定义；保留尺寸、位置、开关等偏好。自定义过的动作定义和视频不自动替换。若之前没有安装 Claude 形态，新形态保持隐藏，可从换装菜单中选择。卸载插件不会自动删除角色文件和偏好。

本分支使用原版的 `dsh-pet` 插件 ID，作为原版替代安装，请勿同时安装两者。配置和文件宠物仍位于 `$DSH_HOME/dsh-pet/`，原版形态和其他已安装宠物继续可用。
